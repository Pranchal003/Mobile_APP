# Mobile_APP
# 🎙️ Voice-Enabled React Native Mobile App (Expo)

A cross-platform mobile application built using **React Native and Expo**, featuring voice recognition, tab-based navigation, and modular component architecture. The project demonstrates real-world mobile development workflow including emulator setup, debugging, and native feature integration.

---

## 🚀 Features

- 📱 Cross-platform mobile app (Android + Web support)
- 🧭 Tab-based navigation using Expo Router
- 🎤 Voice recognition integration
- 🔔 Notification context management system
- 🧩 Modular and reusable components architecture
- ⚙️ Android Emulator support (Android Studio)
- 🔄 Real-time state updates using Context API

---

## 🛠️ Tech Stack

- React Native
- Expo SDK
- Expo Router
- JavaScript / TypeScript
- Context API
- Android Studio Emulator
- Node.js & npm

---

## 📁 Project Structure

app/              → Screens (Expo Router routing)
components/       → Reusable UI components
assets/           → Images, icons, static files
hooks/            → Custom React hooks
context/          → Global state management
constants/        → App constants and configs
